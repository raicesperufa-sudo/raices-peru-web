# Sitio web de Raíces Perú

Prototipo estático preparado para GitHub Pages.

## Estado

- Arquitectura y textos institucionales implementados.
- Nueve páginas responsivas y accesibles: cinco institucionales, una portada de blog y tres historias.
- Sin formularios, descargas, venta, testimonios ni materiales de terceros.
- Logo completo provisional sobre fondo beige.
- Canal de reserva por correo: `raicesperu.fa@gmail.com`.
- Canal público de seguimiento: `https://www.facebook.com/RaicesFamiliasPeru/`.
- Paleta final: marfil cálido, azul protagonista, terracota accesible y verde salvia secundario.
- Sistema visual propio con ondas, órbitas, conexiones y marcos orgánicos construidos en CSS.
- Imagen familiar autorizada incorporada en formato WebP optimizado; el isotipo permanece dentro de fondos compatibles, sin alterar ni forzar su transparencia.
- Dos fotografías autorizadas y optimizadas: una familia en la sección de red y una conversación familiar en “Cómo acompañamos”.
- Isotipo visible en la cabecera y el pie de todas las páginas.
- Iconos acompañan números y textos en modalidades, recorrido, principios, responsabilidades y materiales para facilitar el reconocimiento visual.
- Blog editorial con historias sobre el origen de Raíces, el sentido del nombre y la inspiración del queñual, separando experiencia, filosofía e información verificable.
- Tarjetas y artículos del blog enriquecidos con recursos visuales propios: propósito de Raíces, árbol queñual ilustrado y universo narrativo de Queñal y sus compañeros.
- Carrusel accesible de cuatro imágenes con controles, indicadores, navegación por teclado y adaptación móvil.
- Metadatos sociales básicos y color de navegador configurados en todas las páginas.
- Archivo `robots.txt` incluido para la publicación futura.
- Portadas propias de materiales y recursos visuales optimizados para web.

## Publicación

El contenido de esta carpeta está preparado para publicarse directamente desde la raíz de un repositorio de GitHub Pages.

El sitio no usa rutas absolutas ni servicios de servidor, por lo que funciona tanto en un dominio principal como bajo el subdirectorio habitual de GitHub Pages.
